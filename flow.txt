Request Flow (The DB Shield Pattern):
1. 100,000 internal VCN requests hit the App Nodes directly and are routed by Nginx.
2. The requests bypass the database entirely and hit Redis on the State Node.
3. Redis evaluates the single-threaded Lua Script in microseconds. 
   -> It atomically checks stock and decrements it.
4. The 500 "Winners": 
   -> Receive a success code from Redis.
   -> Proceed to open a database transaction.
   -> Perform a simple, lock-free INSERT into the MySQL orders table.
5. The 99,500 "Losers":
   -> Receive a SOLD_OUT code from Redis.
   -> Are instantly rejected without ever opening a database connection.

Result: 
Absolute data integrity. Zero overselling. Zero HikariCP connection pool starvation. Peak throughput of 9,317 RPS over the internal VCN.
